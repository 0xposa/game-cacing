# 🐍 Game Cacing Sederhana (Snake Game)

Game cacing klasik berbasis Web yang ringan dan responsif, dibuat menggunakan HTML5 Canvas, CSS, dan JavaScript tanpa dependensi eksternal.

## ✨ Fitur
- **Responsive & Mobile Friendly**: Dilengkapi kontrol D-Pad virtual dan swipe touch khusus pengguna HP.
- **Dukungan Keyboard**: Tombol Panah (Arrow Keys) dan W, A, S, D.
- **Audio Sintetis**: Efek suara sintetis menggunakan Web Audio API tanpa perlu file audio tambahan.
- **High Score**: Skor tertinggi tersimpan secara lokal di browser (`localStorage`).

## 🎮 Cara Bermain
1. Buka file `index.html` di browser Anda.
2. Gerakkan cacing untuk memakan apel merah.
3. Hindari menabrak dinding dan tubuh cacing itu sendiri!
